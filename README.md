Purpose of the shitantwan-site: create and maintain a web site hosting poems and articles written by one grew up from town Shitantwan of city Wuxi China in the 1941-1960s.
The poems and articles are saved in encwgwg@gmail.com's Google Drive -> folder "misc" -> Google doc "old_articles".
The web site is saved in GitHub: encwgwg/2ndWegpageTrial/shitantwan-site/
The web site is published in render.com, link address: https://shitangwan-memories.onrender.com/
If new poem or article is added to "old_articles", the update process would be:
step 1: new poem, article, picture added to Google doc "old_articles" in Google Drive folder "misc".
step 2: ask ChatGPT Site to read the updated Google Doc, compare with current shitantwan website, extract new content of text and picture.
step 3: ChatGPT Site updates index.html and the asset folder, add new text, date and matching picture, update navigation and article counts, check readability, mobile layout and link.
step 4: ChatGPT Site commits to GitHub branch: shitangwan-site.
step 5: Render automatically re-deploy the web site.
step 6: ChatGPT Site verify the live website.
